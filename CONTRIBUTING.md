# Contributing to DR Disso projects

We welcome defensive security improvements, documentation, tests and accessibility work.

1. Fork the repository and create a feature branch.
2. Never include production logs, banking records, credentials, camera feeds or personal information.
3. Run `python -m unittest discover -s tests -v` and include tests for changes.
4. Open a pull request using the template. Describe the threat model and limitations.
5. Security vulnerabilities: use private GitHub Security Advisories rather than public issues.

Maintainers review contributions before merging. A public repository does not automatically grant write access.
