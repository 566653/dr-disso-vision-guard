# Camera security posture / Sécurité des caméras

**DR Disso** | Public open-source research prototype | Python + JavaScript

## English

Assess authorized CCTV device availability, TLS settings and firmware age using supplied data.

Try the example: `python engine.py data/sample.json`. Open `web/index.html` for a local browser demo.

We welcome **defensive** contributions: test cases, accessibility improvements, input validation, documentation, and reviewed connectors to systems you are authorized to monitor. Start with [CONTRIBUTING.md](CONTRIBUTING.md) and open a pull request.

**Limitations:** This project currently uses explainable offline rules. It is not a trained AI product, production monitoring service, antivirus, remote camera controller or satellite command system. No institutional endorsement is implied.

## Français

Assess authorized CCTV device availability, TLS settings and firmware age using supplied data.

Essayez `python engine.py data/sample.json`, puis ouvrez `web/index.html` pour la démonstration locale.

Nous accueillons les contributions défensives : tests, documentation, accessibilité, validation des données et connecteurs autorisés. Consultez [CONTRIBUTING.md](CONTRIBUTING.md), puis proposez une *pull request*.

**Limites :** prototype hors ligne fondé sur des règles explicables. Aucun modèle IA entraîné ni connexion réelle aux systèmes sensibles n'est inclus.
